# Aplicatii finale - lectia 01

Trei aplicatii capstone. **Trebuie sa le faci pe toate trei** inainte sa
treci la lectia 02. Fiecare integreaza notiunile din lectia 01
(`Thread`, `Runnable`, `Callable`, `ExecutorService`, `synchronized`,
daemon, `join()`) intr-un scenariu din lumea reala.

| # | Aplicatie | Scenariu |
|---|-----------|----------|
| 1 | [Sistem de plati bancare (ATM)](1-atm-banking/README.md) | 3 conturi, 8 tranzactii ATM procesate in paralel |
| 2 | [Vanzare bilete concert](2-vanzare-bilete/README.md)     | 80 clienti se bat pe 50 bilete |
| 3 | [Sistem de vot online](3-vot-online/README.md)           | 1000 voturi paralel, 3 candidati, dashboard live |

Fiecare are propriul README cu cerinte (Done When) si propriul folder
de solutie in `../../../final/src/aplicatie_finala/N-...`.
